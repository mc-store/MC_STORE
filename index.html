Frequently asked questions

Can I pay on this website?

Not in this demo. Online payment needs a payment provider, a secure backend and server-side order verification.

Will the cape code arrive automatically?

Not yet. Automatic delivery requires a secure code inventory and backend that releases a code only after payment is verified.

Why is a cape marked unavailable?

Its listing is currently marked unavailable in this demo. Availability must be updated by the shop owner based on actual inventory.

Are all capes official?

MCSTORE does not claim affiliation with Mojang or Microsoft. Check the source and terms for each item before buying.
